# Frontend

React/TypeScript/Vite dashboard for the ShelfSync API. Run `npm ci` and `npm run dev` from this directory while the API runs on localhost:5000. Sign-in credentials are configured using `../scripts/Set-Operator.ps1`.

`npm run build` produces static assets for the backend release package. `npm run lint` checks source. The root README and `docs/local-release.md` cover complete setup, verification, and limitations.
