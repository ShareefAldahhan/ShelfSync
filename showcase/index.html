02 / THE ENGINEERING

Built for the awkward cases.

01

Two requests. One last item.

Inventory row locks serialize competing decisions. Availability, order writes, audit events and replay results commit together.

02

The response never arrives.

Idempotency keys let a client retry an uncertain mutation without repeating stock changes. Reusing a key with a different payload is rejected.

03

Payment takes its time.

Checkout protects the stock hold while the provider result is uncertain. Only verified payment makes a customer order eligible for picking.

React UI → Identity + CSRF → Transactional services → PostgreSQL

Provider reconciliation and reservation expiry run as background workers. Customer, Associate, Manager and Admin permissions are enforced by the API.

03 / MEASURED, NOT ASSUMED

A bottleneck worth finding.

Load testing exposed separate account and inventory connection pools exhausting PostgreSQL. A shared, bounded pool removed the errors in the final run.
