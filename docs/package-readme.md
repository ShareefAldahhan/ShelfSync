# ShelfSync local application package

This package contains the compiled API and dashboard. It requires .NET 10 runtime and a configured PostgreSQL database with the ShelfSync schema. It does not include real credentials or automatically create/reset your database.

On the original development machine, first configure the operator using `scripts/Set-Operator.ps1` from the source repository if you have not done so. The published assembly uses the same Development user-secrets identity as the source project.

From the extracted package directory, run in PowerShell:

```powershell
$env:ASPNETCORE_ENVIRONMENT = 'Development'
dotnet .\ShelfSync.Api.dll --urls http://localhost:5000
```

Open http://localhost:5000 and sign in with your configured operator account. Stop with Ctrl+C. Bind only to loopback for this local HTTP setup.

On another machine, configure `ConnectionStrings__ShelfSync`, `Operator__Username`, and `Operator__PasswordHash` privately before startup. The hash must use ASP.NET Identity format, as generated by the source repository's operator-setup script. Never use a raw password as the hash or commit secret configuration files.

`release.json` identifies the source revision, build time and whether local changes existed when built. Verify the ZIP with the adjacent `.sha256` file before distributing it. For setup, schema, verification scripts and architecture, use the source repository documentation.

Public HTTPS hosting, reverse-proxy configuration and durable data-protection key storage require deployment-specific work. This package is a local portfolio release, not a preconfigured public service.
